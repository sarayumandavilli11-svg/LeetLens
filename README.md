# 🔍 LeetLens - Live LeetCode Analytics Dashboard

### 🚀 Live Demo: https://g9vtg8ces4pytzv5herxsq.streamlit.app/

LeetLens is a Streamlit dashboard that visualizes your LeetCode journey - tracks progress, difficulty breakdown, streaks & more!

### ✨ Features
- 📊 LeetCode Stats Visualization
- 🔥 Streak & Progress Tracker
- 🧠 Easy / Medium / Hard Breakdown
- Built with Python, Streamlit, Pandas, Plotly

### 🛠️ Tech Stack
Python | Streamlit | Pandas | Plotly

### ▶️ How to Run
pip install -r requirements.txt
streamlit run app.py
